# Project Scope

## Aim

Identify the main business services in an e-commerce platform and model how they interact using Service-Oriented Architecture (SOA) principles.

## In scope

- Identify business capabilities and assign them to services.
- Describe each service's responsibilities and example operations.
- Document REST-style API endpoints.
- Model the order placement interaction.
- Explain how services communicate and coordinate.
- Provide an academic demonstration of a modular backend design.

## Out of scope

- Real payment processing or storage of payment card data.
- Real shipping or carrier integrations.
- Production-grade authentication and security.
- Multiple independently deployed servers.
- A complete commercial e-commerce platform.

## Assumptions

- Customers use a web frontend.
- The frontend calls the backend using HTTP APIs.
- Backend service modules have clear responsibilities and interfaces.
- Payment and delivery outcomes are simulated in any future demonstration.

## Expected outcome

A repository containing project documentation and a starter application structure that demonstrates how an e-commerce system can be analyzed and modeled using SOA.
